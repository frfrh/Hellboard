# Stratagem names: English (icon repository) ↔ German (game)

Reference for the stratagem catalog (implementation plan §6.11). Read from the in-game ship management screen ("Schiffsmanagement → Taktikausrüstungen", German UI, game version 01.007.101) on 2026-10-15. The English names are the SVG file names of `nvigneux/Helldivers-2-Stratagems-icons-svg`, the group is the repository folder.

The game list shows short names; the detail panel shows the full designation (e.g. "MG-43-Maschinengewehr" for "Maschinengewehr").
